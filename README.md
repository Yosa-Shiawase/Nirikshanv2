# National LE Command Centre | SIH26184

Tactical-grade predictive cybercrime command dashboard for rapid money-trail containment, QR reverse-debit fraud detection, and Section 102 BNSS / CrPC legal proportionality compliance.

## System Capabilities
- Predictive Risk Map: Spatial-temporal Hawkes process model forecasting ATM liquidation contagion.
- Dynamic Time Scrubber: Interactive forecast intervals (NOW, +2h, +6h, +24h).
- Multi-Hop Money Trail (DAG): Hop-attenuated decay tracking from victim through mule layers to final cash-out nodes.
- QR Forensic Analyzer: Optical camera and snapshot sensor auditing UPI payment strings against reverse-debit heuristics.
- Section 102 BNSS Compliance Dossier: Generates cryptographic, download-ready legal intelligence PDFs aligned with the August 2026 Rajasthan High Court mandate.
- Tactical Palettes: 5 switchable mission-ready themes (Cobalt Navy, Emerald Radar, Amber CRT, Bloodhound Crimson, Stealth Monolith).

## Quick Start / How to Run

### Prerequisites
- Python 3.8+
- Any modern web browser (Chrome, Brave, Edge, Firefox)

### Installation & Launch
1. Clone the repository:
   git clone https://github.com/YOUR_GITHUB_USERNAME/national-le-command-centre.git
   cd national-le-command-centre

2. (Optional) Ingest synthetic complaint stream:
   python generate_data.py

3. Start the command server:
   python server.py

4. Open in browser:
   Navigate to http://localhost:8080/
